The category

Legitimate governance — not surveillance.

This is the same category as Google Vault, Microsoft 365 Purview eDiscovery, and GitHub audit logs: monitoring the company-owned tooling the company pays for and provides — not general workforce surveillance. Claresso governs one thing — the AI coding tools your organization issues — and it does it in the open.

Principles

What Claresso never does.

Visible, non-covert agent

Employees can see it's running. The install is named and discoverable; monitoring is disclosed in your policy, never hidden. No keylogging, no biometrics — ever.

Metadata-default, content as a tier

Start with usage metadata. Full-content capture is a deliberate, policy-gated tier — turned on knowingly, not by default.

Secrets & PII redacted at capture

Findings store a redacted preview only — the raw secret never lands in the index. Detection happens the moment content is captured.

The console audits itself

Every admin action in Claresso is itself logged. Reviewers don't get a back door; they get an accountable, self-audited record.

The hard "never" lines

Things we will not build.

No covert-by-default captureIf it isn't disclosed and discoverable, we don't ship it.
No keystroke dynamics or biometricsNo webcam, no voiceprint, no typing-cadence profiling.
No emotion inferenceA hard line under the EU AI Act and our own principles.
No personal-account captureClaresso governs company-issued tooling only — not personal accounts.
